# Editing Guide

## Main content
- Homepage: `index.html`
- Services: `services.html`
- Delivery: `delivery.html`
- Industries: `industries.html`
- About: `about.html`
- Capability statement: `capability.html`
- Contact: `contact.html`

## Branding
Replace files in `assets/brand/` while keeping the same filenames to update logos without editing HTML.

## Styling and animations
- Main stylesheet: `assets/css/style.css`
- Site behaviours: `assets/js/site.js`
- Reusable logo-wall markup: `components/technology-logo-wall.html`

## Future versions
Update `VERSION.txt` and add a new entry at the top of `CHANGELOG.md` for every release.
