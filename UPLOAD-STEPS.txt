 Upload into the existing GitHub repository
1. Download and extract the ZIP file.
2. Open the existing GitHub repository: simonsyamando-create/verticsecurity-website.
3. Select Add file, then Upload files.
4. Open the extracted vertic-security-premium-v3 folder.
5. Select every item inside the folder. Upload the files and folders themselves, not the outer folder.
6. GitHub will replace files with matching names and add the new delivery.html page.
7. Use commit message: Deploy Vertic Security premium V3.
8. Commit directly to the main branch.
9. Open the Actions tab and wait for the Pages deployment to complete successfully.
10. Open the website in an InPrivate window or hard refresh with Ctrl+F5.

 Do not change
- Keep the included CNAME file in the repository root.
- Do not change GoDaddy DNS or Microsoft 365 email records during this website upload.
