# Vertic Security V7 upload instructions

1. Extract this ZIP.
2. Open the repository root in GitHub.
3. Upload the files and folders inside this package, not the outer package folder.
4. Allow GitHub to replace `index.html` and `contact.html`.
5. Keep the existing `CNAME` file and existing brand files.
6. Commit with: `Deploy Vertic Security V7 management layer`.
7. Open GitHub Actions and wait for Pages deployment.
8. Hard refresh the website.
